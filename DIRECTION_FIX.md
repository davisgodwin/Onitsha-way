# v0.13.1 — Direction marker restored

- Always-visible compass with a rotating north arrow and camera-facing heading.
- A marked destination takes priority; otherwise the tracked job supplies directions.
- Large direction arrow, destination name and distance, with street-route guidance.
- Direct bearing remains available when street routing is unavailable.
- Tap the direction marker to open Map (M); tap the separate custom-marker chip to clear it.
- Navigation, job and destination chips flow below the weather instead of overlapping the clock.
- Existing minimap routes and golden world destination beacon are preserved.
- Existing story, careers and save format are unchanged. No new game required.

Export a valuable save before upgrading. Extract the source to a new folder, run `npm ci` and `npm run dev`, then open Vite’s printed address. Keep the same site address or import your exported save. Do not clear browser storage.
