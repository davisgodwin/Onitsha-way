ONITSHA WAY v0.34.0 — PLAY ON YOUR PHONE (SAME WI-FI)

Read UPDATE_34.md for the full guide and troubleshooting; TEST_RESULTS_34.md for checks.
1. On the host PC: stop npm run dev (Ctrl+C). Start MySQL in XAMPP if you use it.
2. Run: npm run lan
3. Windows firewall prompt: tick PRIVATE networks only, then Allow access.
4. On the phone (same Wi-Fi): open the http://192.168....:5180 address the terminal prints.
5. New accounts on other devices need the JOIN CODE printed in the terminal. Logging in does not.
Hostel/cafe Wi-Fi often blocks this - use a phone hotspot instead (connect the PC to it, run npm run lan again).
Voice chat works on the host PC only (phones would need https). Use trusted Wi-Fi: it is plain http.

ONITSHA WAY v0.27.3 — ORIGINAL LOADING SCREEN + NPM RUN DEV

START
1. Back up your old save with Settings > Export save. Keep your own server/data folder.
2. Extract this release into a fresh folder. Install Node.js 22 LTS or newer.
3. If upgrading, copy your OWN server/data folder from the previous installation into this project.
4. In the folder containing package.json, run: npm ci
5. Start the game with: npm run dev
6. Open http://localhost:5173 when the terminal prints its Local URL.
7. Keep this terminal open. Ctrl+C stops both the game and account server.

SIGNUP / LOGIN
The original warm ONITSHA WAY loading screen now contains the signup form.
New players: enter display name, username, password (10+ characters), and confirm 18+.
Returning players: choose Log in. Keep me logged in is selected by default.
After authentication, the same splash loads the city. A new account opens character
creation; an existing character in this browser resumes automatically.
An old offline-save option appears only if this browser has a legacy offline save.
No separate green welcome page or extra Account app was added.

UPGRADE SAFETY
Accounts live in server/data/world.json. Back up your OWN server/data folder.
Character progress is stored separately per account in this browser's localStorage.
Keep the same browser profile and http://localhost:5173 address when returning.
Changing devices or browser profiles does not transfer character progress automatically.
Never delete server/data or clear browser storage to fix a startup error.
The source ZIP does not contain any player accounts or private server data.

COMMANDS
npm run dev        Starts account/multiplayer server AND Vite together.
npm run local      Compatibility alias for the same combined launcher (not required).
npm run dev:client Frontend only; advanced use when the account server already runs.
npm run build      Builds the production frontend in dist/.
npm run preview    Previews dist/; account features still require the backend.

TROUBLESHOOTING
Stop the previous game terminal before starting this release.
If port 8787 or 5173 is occupied, stop the old process and run npm run dev again.
A failed startup does not require removing saves or account data.
The backend deliberately stays on loopback; do not expose this local prototype publicly.
Do not use an important password. No email verification or password recovery yet.
All advertising/payment buttons remain TEST simulations. No real money is charged.

RETAINED UPDATES
- Switchable home lights, fitted kitchens, larger bathrooms, solar street lamps.
- Original instrumental Afrobeat-style club/bar tracks; no commercial artist recordings.
- HD/Ultra mobile graphics controls and mobile HUD minimize/restore.
- Skill XP/level feedback, shared training cooldown, correct Comedy qualifications.
- Existing phone, careers, housing, vehicles, furniture and community features retained.

NOT YET IMPLEMENTED
- Upper Iweka monument has not been verified or added.
- Production database/cloud-save migration and secure server-authoritative progression.
